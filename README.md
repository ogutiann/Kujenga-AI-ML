## Project Overview

Every rainy season, Kampala floods. This project models how floodwater spreads
zone by zone through Kampala's drainage network -- treating it like an epidemic --
and identifies which single zone, if upgraded, would reduce flood spread the most.

**Research Questions:**
1. Can flooding spread be modelled using a SIR epidemic process? (R0 = 1.255)
2. Does rainfall predict displacement? (R2 = 0.937, p < 0.001)
3. Do valley zones flood more often than hillside zones? (Cohen's d = 2.44)
4. Which drainage zone has the highest flood-spread centrality? (Nalukolongo, PR = 0.342)

---

## Techniques Used (from Kujenga AI/ML course)

| Technique | Application |
|---|---|
| **SIR Epidemic Model** | Models flood spread through drainage network; calibrates beta and gamma from historical events |
| **Linear Regression** | Predicts people displaced from rainfall intensity; R2 = 0.937 |
| **Hypothesis Testing (t-test)** | Tests whether valley zones flood significantly more often than hillside zones |
| **PageRank** | Ranks drainage zones by flood-spread centrality to identify infrastructure priorities |

## Key Results

| Analysis | Result | Interpretation |
|---|---|---|
| SIR Model | R0 = 1.255 | Flooding spreads to multiple zones in 79% of events |
| Linear Regression | R2 = 0.937 | Rainfall explains 93.7% of displacement variation |
| t-test | Cohen's d = 2.44 | Valley zones flood 3x more often than hillside zones |
| PageRank | Nalukolongo PR = 0.342 | Priority zone for drainage infrastructure investment |

---

## Policy Recommendations

1. **Upgrade Nalukolongo's drainage first** -- highest PageRank means greatest network-wide benefit
2. **Issue warnings at forecast rainfall >= 80mm** -- displacement escalates sharply above this
3. **Clear all channels before each rainy season** -- halving beta substantially reduces peak flooding
4. **Designate Bwaise and Kalerwe as permanent high-risk zones** -- flooded in >78% of all events

---

## Limitations

- 28 events compiled from secondary sources; rainfall figures are reported estimates
- SIR model assumes uniform beta and gamma across all zones
- Only 2 hillside zones limits t-test statistical power
- Correlation does not imply causation
